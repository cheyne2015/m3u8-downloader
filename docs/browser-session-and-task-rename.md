# 深度提取会话与任务文件同步改名（2.2.4 本地测试版）

## 原因与边界

2026-11-01 对 ly.simuwang.com/roadshow/9529.html 的独立、未登录浏览器检查：默认 HeadlessChrome 标识的主文档返回 500，随后跳转到首页；只调整为桌面 Chrome 标识，主文档返回 200，播放器脚本明确提示需要登录。用户确认迅雷使用的是已经登录、可播放的浏览器。这是导航兼容与登录会话两层差异，不能将跳转首页或取得网页标题算作识别成功。

此前任务设置中的 Cookie、来源地址和浏览器标识仅传入 HTTP 会话，没有传入深度提取浏览器。现在从目标页面的已准备请求中提取这三项设置，送入每个任务独立的浏览器环境。请求头格式的 Cookie 用浏览器 Cookie API 绑定原页面主机，不作为全域请求头；JSON 导出则保留原有域名和路径范围，支持同站 API 所需的父域 Cookie。常驻 worker 的各任务不共享 Cookie。单次 worker 用临时进程环境传递，不写命令行；常驻服务通过标准输入传递。不会读取用户浏览器账号，也不绕过网站登录要求。

真实网站的登录后提取仍须有效的任务登录信息，本次未读取用户现有浏览器凭据，也未声称完成该网站登录后识别。深度组件 1.1.4 的 runtime.json 增加 browser_session_version=1；新主程序发现旧组件时提示升级。

后续兼容浏览器导出 JSON：`cookie_input.py` 接受请求头、Cookie 数组及包含 cookies 数组的对象。新输入在保存前校验并继续 DPAPI 加密，旧版本已经加密保存的 JSON 也在使用时解析。HTTP CookieJar 与浏览器环境保留域名、路径、有效期和安全属性，不解码或改写 Cookie 值；不匹配当前来源网站的域名不导入。深度组件升级到 1.1.5，browser_session_version=2。界面及适配回归 169 项、兼容专项 15 项、真实浏览器会话用例 7 项分别验证（有重叠），未使用用户提供的真实登录凭据作为测试数据。

## 主动登录提示

深度组件 1.1.6 检查明确的播放器登录提示、网页脚本登录错误和主文档 HTTP 401。仅在没有播放候选时返回专门的 LoginRequiredError；通用“未找到链接”、导航栏“登录/注册”、其他 HTTP 错误不据此判断。候选已发现时优先保留候选，用户停止不触发登录提示。进程内、常驻服务与单次 worker 使用同一异常类型/协议，单次 worker 退出码为 5。

协调器遇到明确登录要求即停止自动重试与模式切换。保持原有 failed 存储状态，用固定错误标记呈现“需要登录”，不新增数据库字段或枚举值。后台完成信号触发填写提示；同站每进程只自动提示一次，同时最多一个提示框。暂不填写保留状态，右键“填写登录信息”始终可用；保存非空登录信息后自动重新提取。

登录信息保存时立即加密写入同站配置，不必等待提取成功。同一完整主机名的新任务自动复用，已有空登录信息任务在开始提取时补用；旧版本仅在任务中保存的信息也可复用。单个任务已有的登录信息优先，不向其他子域扩展，不自动重启其他失败任务。晚结束的旧任务不能用旧登录信息覆盖新保存的信息；更新登录信息也不覆盖网站原先学习的超时和模式参数。

对用户提供路演地址的未登录实测已返回 LOGIN_REQUIRED；不代表已经验证用户账号登录后的媒体下载。228 项相关回归及 20 项登录/浏览器会话用例通过；另验证登录短语判断、同站提示去重、取消保留状态、保存后重新提取及后台完成信号。

## 同步改名行为

此前 rename_task 只保存任务名称。现在任务改名时，两阶段重命名实际存在的已完成文件，并在同一 SQLite 事务中保存名称和文件路径；不覆盖已有无关文件。同名自动追加序号，文件移动失败时回退已移动的文件。多文件沿用现有网页标题文件夹，名称采用新任务名及两位序号。

正在下载和保留分片缓存的项不立即改路径；正常下载完成后按新任务名改名。完成文件被单独重命名后，仅校验修复不会再次按任务名覆盖。文件缺失时保留原路径记录，避免伪造已重命名。正在校验、修复或导出的任务暂不接受改名，避免后台用旧路径写回。任务数据库不新增字段。

## 验证

本地 HTTP 与真实 Chromium 覆盖浏览器标识、Cookie/来源地址复用、跨域 Cookie 隔离、常驻任务间会话隔离、单次 worker 私密参数传递，以及原有网络/内嵌页面发现：19 项通过。打包后的 1.1.4 常驻 worker 在同一登录门控页面成功发现播放列表，且未向其他主机发送 Cookie。

改名专项 10 项通过：单文件、多文件、重名、移动失败回退、在途下载完成、分片缓存身份保留、丢失文件、大小写改名、下载协调器及真实 Qt 右键入口。相关提取/下载/界面回归分别完成 212 项和 154 项（有重叠），未将它们相加成总测试数。
