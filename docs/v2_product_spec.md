# m3u8 下载器 v2 产品规格

状态：已确认，进入实现  
目标：重建为类似迅雷任务管理器的 Windows 图形下载工具。

## 1. 产品结构

- 正式版只提供图形界面，不再发布命令行版本。
- 主界面左侧包含“下载中”“已完成”“设置”。
- 中间显示父任务列表，右侧显示当前父任务详情，底部始终显示日志。
- 一个网页地址或一个 m3u8 直链对应一个父任务。
- 网页提取到的每条 m3u8 对应一个子下载项。
- 正式版使用 PySide6 重建界面，下载、提取、解析、断点续传和合并能力从现有核心迁移复用。

## 2. 新建任务

- 点击“新建链接”打开弹窗，默认显示地址、保存目录和开始按钮。
- 保存目录默认使用上一次创建任务的目录。
- 地址输入支持一条或多条链接，每行一条；批量创建时每条链接生成独立父任务。
- 自动去除空行和本次输入中的重复地址。
- 地址可为网页或 m3u8；程序通过地址和响应内容判断类型。
- m3u8 直链直接进入下载队列；网页地址进入提取队列。
- 重复地址命中已有任务时定位原任务，并允许继续、打开或明确创建副本。
- 创建副本时自动处理输出文件重名。

### 2.1 高级选项

新建弹窗提供默认收起的高级选项：

- 本任务提取模式
- 本任务代理
- 来源地址
- 浏览器标识
- 登录信息
- 本任务限速

敏感登录信息不得写入普通日志，持久化时使用 Windows 当前用户级加密。

## 3. 网页提取

- 默认使用“智能模式（深度优先）”。
- 深度模式不可用、失败或没有候选时自动回退普通模式。
- 另提供“仅深度模式”和“普通模式”。
- 默认同时提取 3 个父任务，可设置 1～6。
- 提取与下载使用独立队列和并发槽。
- 提取结果流式显示，标题晚到时更新父任务和未开始的输出名称。
- 用户未点击停止时，提取会自然运行到结束。
- 提取过程中用户可以选择当前候选并开始下载，提取仍继续。
- 一旦用户手动选择并开始下载，后续发现的候选只追加为未选中，不自动加入下载。
- 用户停止提取时保留当前候选，并把它们作为最终结果应用自动下载规则。
- 暂停后继续提取会重新执行完整提取，并按 URL 合并去重；用户也可直接使用已发现候选。

## 4. 自动选择

- 自动下载候选数量阈值默认 3，可设置 1～20。
- 提取自然结束且用户没有手动接管选择时：
  - 有效候选数为 1～阈值：全部自动勾选并进入下载队列。
  - 有效候选数超过阈值：父任务进入“待选择”。
- 不可达或解析失败候选不计入阈值。
- 修改全局阈值只影响之后创建的任务；已有任务保存自己的设置。

## 5. 下载调度

- 默认同时下载 3 个父任务，可设置 1～6。
- 每个父任务内部一次只下载一个 m3u8 子项。
- 每个 m3u8 内部默认使用 8 个 TS 分片线程，可设置 1～32。
- 父任务按创建顺序排队，支持移到最前、上移、下移、移到最后和优先下载。
- 优先下载不强行中断正在运行的任务。
- 暂停父任务会停止当前子项并暂停其余待下载项，立即释放全局下载槽。
- 继续父任务时优先续传中断子项，再处理其余已选项。
- 提取中、待选择、已暂停和重试等待任务不占下载槽。
- 程序重启后保留调度顺序。

### 5.1 失败与重试

- 单次网络请求默认重试 3 次。
- 任务级自动重试默认 1 次，可设置 0～5；等待 30 秒后执行且等待期间不占下载槽。
- 超时、断线和服务器 5xx 可做任务级自动重试。
- 403、404、加密密钥错误等明确错误直接标记失败。
- 失败项使父任务保留在“下载中”，提供重试失败项。
- 用户主动跳过的子项视为已处理，不阻止父任务完成。

### 5.2 限速

- 全局下载速度默认不限速。
- 全局限速由正在运行的父任务公平共享。
- 父任务可设置独立限速，但不能突破全局总限速。
- 首版不包含分时段限速。

## 6. 状态

父任务显示状态：

- 等待提取
- 提取中
- 待选择
- 等待下载
- 下载中
- 合并中
- 已暂停
- 重试等待
- 部分失败
- 已完成

子下载项显示状态：

- 未选择
- 等待下载
- 下载中
- 已暂停
- 重试等待
- 失败
- 已跳过
- 已完成

提取和下载可以同时进行，因此内部必须分别保存提取状态和下载状态。界面可显示“下载中 · 仍在提取”。

## 7. 完成规则

- 所有已选子项为“已完成”或“已跳过”时，下载部分视为处理完毕。
- 网页提取仍在运行时，父任务继续留在“下载中”，显示“下载已完成 · 仍在提取”。
- 提取结束或被用户停止后，所有已选项均已处理的父任务进入“已完成”。
- 未选择任何候选的网页任务在提取结束后进入“待选择”，不能成为已完成。
- 网络失败不等于用户跳过，失败项会阻止父任务完成。

## 8. 候选选择

- 待选择时可任意勾选，点击“下载选中项”后加入父任务内部队列。
- 正在下载和已完成项锁定勾选状态。
- 尚未开始项可以取消选择或追加选择。
- 已完成项可单独重新下载。
- 待选择任务不占下载槽。

## 9. 命名与目录

- 网页任务初始名称使用网页完整标题。
- 单个 m3u8 保存为“任务名称.mp4”。
- 多个 m3u8 自动建立“网页标题”文件夹，子文件保存为“任务名称_01.mp4、任务名称_02.mp4……”。
- 候选具有可靠标题或清晰度标签时优先纳入文件名，重名时追加序号。
- 直接 m3u8 优先使用地址路径中的有效名称；`index`、`playlist`、`master`、`media` 等通用名称改用上级目录；仍无有效名称时使用“新建任务_时间”。
- 不把域名、签名参数或令牌写入任务名和文件名。
- 冲突文件自动追加 `(1)、(2)…`，不弹窗阻塞调度。
- 下载前修改父任务名称会影响尚未开始项的自动文件名；已落盘文件保持原名。
- 完成后修改父任务名称只改变显示名称；磁盘文件由“重命名文件”明确修改。

## 10. 进度与磁盘空间

- 提取阶段显示不确定进度动画。
- 父任务优先按所有已选项总字节数加权计算进度。
- 大小未知时使用预估值；全部未知时按已处理项数量显示并标注估算。
- 列表显示总进度、当前速度、已下载/总大小、剩余时间和当前子项。
- 详情显示每个子项的大小、时长、进度、状态和速度。
- 下载前检查磁盘空间，预留预计大小的 10% 加 500MB。
- 空间不足时不启动或安全暂停并释放槽位；大小未知时剩余空间低于 500MB 即暂停。

## 11. 数据与重启

- 使用全新 SQLite 数据库，不迁移、不读取、不修改 v1.6.0 的旧 JSON 数据。
- 默认数据目录为 `%LOCALAPPDATA%\m3u8-downloader\`。
- 程序目录存在 `portable.flag` 时使用程序目录下的 `data`。
- 父任务、子项、选择、顺序、保存路径和任务设置全部持久化。
- 程序关闭、崩溃、断电后，未完成任务下次启动统一恢复为“已暂停”，不自动联网。

## 12. 主界面与日志

- 默认深色主题，支持浅色和跟随 Windows。
- 左侧导航、中间父任务列表、右侧详情、底部固定日志。
- 右侧详情包含“下载项”和“详细信息”两个标签，可调整宽度和临时收起。
- 日志区域可调整高度但不能完全关闭；默认显示选中任务日志，没有选择时显示全部。
- 日志带时间、任务名和类型，支持当前任务/全部任务及级别筛选，默认保留 30 天。
- 顶部搜索任务名称、原始地址、m3u8 和输出文件名。
- 下载中支持状态筛选；已完成支持按名称、完成时间和总大小排序。

## 13. 任务操作

下载中父任务支持：开始/继续、暂停、优先下载、重试失败项、详情、打开目录、重命名任务、复制原始链接、任务设置、删除任务、彻底删除。

已完成父任务支持：详情、打开文件、定位文件、下载项、重新下载、重命名任务、重命名文件、复制原始链接、删除任务、彻底删除。

子项支持：下载/继续、暂停、跳过、重试、重新下载、复制 m3u8、打开文件、定位文件、重命名文件。

- 删除任务保留已完成文件，但清理无任务可恢复的专用临时缓存。
- 彻底删除会展示准确文件清单和总大小，经确认后删除数据库记录、输出文件和专用缓存。
- 绝不删除多个任务共用的整个保存目录。
- 已完成文件被移动或删除时保留任务并标记，支持重新关联文件。
- 重新下载父任务或子项会创建新父任务副本，原完成记录与文件不变。

## 14. Windows 集成

- 只允许一个主程序实例；再次启动时激活已有窗口。
- 有活动任务时关闭窗口，提供最小化到托盘、暂停全部并退出、取消。
- 可设置关闭时直接最小化到托盘，默认关闭。
- 托盘菜单提供显示主窗口、暂停全部、继续全部、退出。
- 父任务全部完成时可发送 Windows 桌面通知；设置项默认关闭。

## 15. 发布

- 正式版为程序文件夹，包含主程序和经过验证的 `ffmpeg.exe`。
- 优先使用随包 ffmpeg，其次使用系统 ffmpeg；均不存在时明确标记兼容拼接模式。
- 先在独立工作树和候选目录验证，不直接覆盖旧版。
- 用户验收候选版后再决定替换和发布。
